# Сборка iFreeRDP (.ipa) — инструкция

Кастомная сборка RDP-клиента iFreeRDP (FreeRDP) с правками под этот проект:

- Liquid Glass оформление (iOS 26): стеклянная расширенная клавиатура, системные бары
- SF Symbols вместо старых PNG-иконок на клавише (стрелки, backspace, Enter, меню)
- Лимит истории быстрых подключений — 30 записей, без дублей
- ПКМ: долгое нажатие на тач-экране, правая кнопка внешней мыши/трекпада, hover, колесо
- Модификаторы Ctrl/Alt/Shift/Win — залипающие, работают и с физической клавиатурой

## Как собрать .ipa

Сборка идёт на GitHub Actions (macOS-раннер), локально ничего не нужно.

1. Создай **пустой** репозиторий на GitHub (public — macOS-минуты бесплатные; private — из бесплатной квоты ~3 полные сборки в месяц).
2. Запушь этот код:
   ```bash
   git remote add myrepo https://github.com/ИМЯ/РЕПО.git
   git push myrepo master
   ```
3. Вкладка **Actions** → workflow «iOS unsigned ipa» запустится сам (или кнопка **Run workflow**). Сборка ~40–70 минут: из исходников компилируются OpenSSL, FFmpeg, OpenH264 и зависимости.
4. Когда загорится зелёным — артефакт **iFreeRDP-unsigned-ipa** → скачать zip → внутри `iFreeRDP-unsigned.ipa`.

## Подпись и установка (Windows)

1. Поставь [Sideloadly](https://sideloadly.io).
2. Подключи iPhone по USB, открой Sideloadly.
3. Перетащи `iFreeRDP-unsigned.ipa`, введи Apple ID (free) → **Start**. Пароль Apple ID + код 2FA спросят при подписи.
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять профилю разработчика.

Подпись бесплатным Apple ID живёт **7 дней** — потом просто повторить пункт 3 (данные закладок внутри приложения при пересборке сохраняются, пока bundle id тот же).

Требование к iPhone: iOS 15.0+ (Liquid Glass отрисуется на iOS 26+, на более старых — стандартный полупрозрачный стиль).
